# Wellesley Fresher

## Overview

Wellesley Fresher is a dining rating website where Wellesley students can rate, review, and provide anonymous feedback on meals from Wellesley Fresh. As Wellesley Fresh is always looking to hear from students about their dining hall experience, Wellesley Fresher aims to make the process easier and more effective, and increase student engagement in shaping the campus dining experience.

## Project Status

This project is currently in the Beta stage.

Current implemented features include:
- Homepage review display
    - Displays the most recent reviews on the homepage with students’ permission
    - Guest users can read reviews without logging in
    - Guest users can see how many “likes” each review has

- Student account features
    - Students can sign up and log in
    - Flash error messages are shown for login, signup, and form submission issues
    - Students can submit feedback, including:
        - Dining hall
        - Meal time
        - Star rating
        - Review text
        - Feedback category
        - Optional image upload
        - Permission to display the review on the homepage
    - Students can like or unlike reviews on the homepage

- Staff account features
    - Staff can log in
    - Flash error messages are shown when needed
    - Staff can access a dashboard for viewing submitted reviews
    - Staff can filter reviews by:
        - Dining hall
        - Meal time
        - Date range
    - Staff can search reviews by keyword or review ID
    - Staff can view a detail page for each review, including uploaded images
    - Staff dashboard results support pagination
    - Staff can view review analytics, including average ratings based on selected filters

- Admin account features
    - Admin users can log in through a separate admin account collection
    - Admin users can access the admin dashboard
    - Admin users have all staff dashboard features
    - Admin users can edit existing reviews
    - Admin users can delete reviews
    - Admin users can replace or remove uploaded review images
    - Admin users can view review analytics using filters for:
        - Date range
        - Dining hall
        - Meal time

Future improvements may include:

- Improved UI styling and visual consistency
- More advanced analytics for staff and admin users
