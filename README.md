# Wellesley Fresher

## Overview

Wellesley Fresher is a dining rating website where Wellesley students can rate, review, and provide anonymous feedback on meals from Wellesley Fresh. As Wellesley Fresh is always looking to hear from students about their dining hall experience, Wellesley Fresher aims to make the process easier and more effective, and increase student engagement in shaping the campus dining experience.

## Project Status

This project is currently in the Alpha stage.

Current implemented features include:

- Display the most recent reviews in the homepage (with students' permission)
- Student sign up and login
    - Flash error messages
    - Student submit feedback (dining hall, meal time, star rating, review text, category selection, image upload)
- Staff login
    - Flash error messages
    - Staff dashboard for viewing reviews
    - Filtering by dining hall, meal time, and date
    - Search by keyword or review ID
    - Review detail page
    - Pagination for staff dashboard results

Future improvements may include:

- Improved UI styling
- More advanced analytics for staff
- Student ability to view, edit or delete their own reviews
